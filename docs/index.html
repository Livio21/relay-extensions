Livio21 Relay extensions

A signed catalogue of Relay music source extensions. Open this page on the device that has Relay installed, then use the button below.

Add to Relay

Relay will fetch the repository descriptor and show you its name and signing-key fingerprint. Nothing is trusted, installed, or enabled until you accept it there.

If the button does nothing, Relay is not installed or the link was opened on a desktop browser. You can add the repository by hand instead — copy this into Settings → Source repositories:

https://raw.githubusercontent.com/Livio21/relay-extensions/main/repository.json Relay accepts Livio21/relay-extensions in that field too, and expands it to the address above.
